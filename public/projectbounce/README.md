# Project Bounce
A static, local-first mobile web app. Open index.html for a browser preview. For installation and offline support, deploy the contents of this folder to an HTTPS static host (for example, Vercel), then use Chrome's install/add-to-home-screen menu. No build, dependencies or server required. This version does not provide native scheduled push; Settings exports an 84-day calendar with two daily events. Import to a dedicated Google Calendar on a computer, verify event notifications and sync to Android. Re-importing may duplicate events; delete the old dedicated calendar first if changing dates. Default start: next Monday (or today if Monday); default times 8 AM and 6 PM. Set your own dates/times in Settings before export. Recovery logs and checkboxes use browser localStorage; export a JSON backup before clearing browser data. No sync, medical data collection, analytics or external APIs. The app intentionally gates exercise checkboxes and advanced phases on self-reported clinician review; this is not medical clearance. Recurrent knee swelling should be assessed before training and impact requires individual clearance. No clinical validation is claimed.

## Repository setup

The ZIP is the original source export. The extracted files are served by the existing Next.js app at `/projectbounce` (or `/projectbounce/index.html`). Run `npm run dev` from the repository root, then open that route. No extra dependencies or build step are required. Installation and offline support require HTTPS, and the service worker is scoped to `/projectbounce/`. All progress remains in this browser; export a backup before clearing browser data.
